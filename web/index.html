Board —

Ordering. Newest first. Applications would sort by closing date where one is published, but none of the ten applicant tracking systems in this set publishes one, so the spine is the posting date.

Dates are not all equally known, and the board does not pretend otherwise. Greenhouse, Ashby, Workable and Lever publish a timestamp. Workday publishes a sentence — Posted 21 Days Ago, or Posted 30+ Days Ago, which is a floor rather than a date. BambooHR and Personio publish nothing, so those fall back to the day we first saw the posting, an upper bound. Anything approximate is marked with a dotted underline and says what it really knows on hover.

Stacking. One firm can hold a thousand openings — U.S. Bank alone accounts for 1,455 — so within each time band a firm with three or more postings collapses to a single stack. Sorting stays global; stacking only changes how much vertical space a firm may occupy before you have asked to see it.

Ties break on fewest openings first. Hundreds of postings share a date, so the tie-break is doing most of the ordering work. A firm with one opening wrote it for one role; a firm with fourteen hundred is staffing branches. Firm name breaks the remaining ties, so the order is stable between renders rather than incidental.
